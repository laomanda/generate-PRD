# Technology Stack

> **Target System**: CareFlow Hospital Suite  
> **Database Engine**: PostgreSQL  
> **Scalability Tier**: serverless_edge  

---

## 1. Technology Stack Overview
Core technology stack for **CareFlow Hospital Suite** tailored for CareFlow Hospital Suite Platform operations.


## 2. Runtime Environment
Node.js >= 20.0.0 LTS / Serverless Edge Runtime environment for processing CareFlow Hospital Suite Patient workflows.


## 3. Core Framework
React SPA (Single Page Application) for CareFlow Hospital Suite.


## 4. Frontend Technologies
React, TypeScript.


## 5. Backend Technologies
Node.js Express Server handling Patient API controllers.


## 6. Database Technologies
PostgreSQL Relational Database instance executing query operations across tables: careflowhospitalsuite_users, patients, doctors, appointments, medicalrecords, prescriptions.


## 7. Libraries & Packages
Zod schemas for Patient payloads, JSZip utilities, and CareFlow Hospital Suite dependencies.


## 8. UI / Styling Technologies
CSS Modules scoping visual components for CareFlow Hospital Suite.


## 9. Animation Technologies
Framer Motion transition effects applied to Doctor UI drawers and screens.


## 10. State Management
Zustand store managing client-side Patient UI cache.


## 11. Data Fetching
TanStack React Query for Patient API requests.


## 12. Forms & Validation
Zod schema validation enforcing contract integrity for Patient, Doctor, Appointments fields.


## 13. Authentication
Session / JWT Authentication for CareFlow Hospital Suite.


## 14. Authorization
Role Permission RBAC engine protecting User, Patient, Doctor, Appointments, MedicalRecords, Prescriptions endpoints.


## 15. API Technologies
REST / JSON OpenAPI 3.0 endpoints for Patient controllers.


## 16. External Integrations
Domain-specific external service endpoints for Patient.


## 17. File Storage
AWS S3 Storage storing Patient digital assets.


## 18. Development Tools
TypeScript, ESLint, Prettier, Vite for careflowhospitalsuite.


## 19. Testing Stack
Vitest unit suite & Playwright E2E asserting Patient workflows.


## 20. Code Quality & Standards
Strict TypeScript rules enforcing type correctness on Patient models.


## 21. Environment Configuration
Environment variables managed via `.env` files.


## 22. Version Compatibility
All third-party libraries pinned to compatible semver ranges.


## 23. Deployment & Infrastructure
AWS ECS Docker Containers hosting careflowhospitalsuite.


## 24. Technology Decisions
Selected React SPA (Single Page Application) for CareFlow Hospital Suite. for serverless_edge performance.


## 25. Technology Rationale
Architecture selected for rapid iteration and high type safety.


## 26. Known Limitations
Cold start latency for serverless functions, and local file storage limitations.
