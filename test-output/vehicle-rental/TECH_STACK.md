# Technology Stack

> **Target System**: Vehicle Rental Management  
> **Database Engine**: PostgreSQL  
> **Scalability Tier**: serverless_edge  

---

## 1. Technology Stack Overview
Core technology stack for **Vehicle Rental Management** tailored for Vehicle Rental Management Platform operations.


## 2. Runtime Environment
Node.js >= 20.0.0 LTS / Serverless Edge Runtime environment for processing Vehicle Rental Management VehicleFleet workflows.


## 3. Core Framework
React SPA (Single Page Application) for Vehicle Rental Management.


## 4. Frontend Technologies
React, TypeScript.


## 5. Backend Technologies
Node.js Express Server handling VehicleFleet API controllers.


## 6. Database Technologies
PostgreSQL Relational Database instance executing query operations across tables: vehiclerentalmanagement_users, vehiclefleets, customers, rentalreturns, vehicles.


## 7. Libraries & Packages
Zod schemas for VehicleFleet payloads, JSZip utilities, and Vehicle Rental Management dependencies.


## 8. UI / Styling Technologies
CSS Modules scoping visual components for Vehicle Rental Management.


## 9. Animation Technologies
Framer Motion transition effects applied to Customer UI drawers and screens.


## 10. State Management
Zustand store managing client-side VehicleFleet UI cache.


## 11. Data Fetching
TanStack React Query for VehicleFleet API requests.


## 12. Forms & Validation
Zod schema validation enforcing contract integrity for VehicleFleet, Customer, RentalReturn fields.


## 13. Authentication
Session / JWT Authentication for Vehicle Rental Management.


## 14. Authorization
Role Permission RBAC engine protecting User, VehicleFleet, Customer, RentalReturn, Vehicle endpoints.


## 15. API Technologies
REST / JSON OpenAPI 3.0 endpoints for VehicleFleet controllers.


## 16. External Integrations
Domain-specific external service endpoints for VehicleFleet.


## 17. File Storage
AWS S3 Storage storing VehicleFleet digital assets.


## 18. Development Tools
TypeScript, ESLint, Prettier, Vite for vehiclerentalmanagement.


## 19. Testing Stack
Vitest unit suite & Playwright E2E asserting VehicleFleet workflows.


## 20. Code Quality & Standards
Strict TypeScript rules enforcing type correctness on VehicleFleet models.


## 21. Environment Configuration
Environment variables managed via `.env` files.


## 22. Version Compatibility
All third-party libraries pinned to compatible semver ranges.


## 23. Deployment & Infrastructure
AWS ECS Docker Containers hosting vehiclerentalmanagement.


## 24. Technology Decisions
Selected React SPA (Single Page Application) for Vehicle Rental Management. for serverless_edge performance.


## 25. Technology Rationale
Architecture selected for rapid iteration and high type safety.


## 26. Known Limitations
Cold start latency for serverless functions, and local file storage limitations.
